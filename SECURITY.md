# Security

Please report a security problem in testslot privately, through GitHub's private vulnerability reporting on this repository, and not in a public issue or pull request. Use this link: https://github.com/jerrydboonstra/testslot/security/advisories/new (or the Security tab, "Report a vulnerability"). Say which version or commit you ran, what you did and what you saw. I aim to reply within 7 days. I will then fix it and credit you if you want to be named. There is no other channel.
